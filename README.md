# Portfolio – Justyna Frankiewicz

Frontend portfolio of Justyna Frankiewicz, built with React and Tailwind CSS.

## 📖 Description

The website showcases:

- "About Me" section
- Education and professional experience
- Technologies and skills
- Contact section with email link and GitHub/LinkedIn buttons
- Responsive design with dark mode support
- Multilingual support (Polish and English)

This portfolio is built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **i18next** for translations.

---

## 🚀 Running Locally

1. Clone the repository:

```bash
git clone https://github.com/justynafrankiewicz/portfolio.git
cd portfolio
```

2. Install dependencies:
   npm install

3. Run the development server:
   npm run dev
